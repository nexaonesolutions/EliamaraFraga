# Reisclinic | Landing Page de Luxo

Landing page de alta conversão desenvolvida sob medida para a **Reisclinic** (Sarandi/PR), especializada em procedimentos estéticos avançados não-invasivos: **Otomodelação Não Cirúrgica** e **Harmonização Orofacial**.

---

## 💎 Design & Identidade Visual

O projeto foi construído seguindo uma estética minimalista e de alto luxo:
* **Paleta de Cores:** Gradients metálicos de *Rose Gold*, tons quentes de *Nude/Champagne* e contraste suave com texturas de *Mármore* e tipografia escura bronze/cacau.
* **Tipografia:** Combinação elegante da fonte serifada clássica **Cormorant Garamond** para títulos e **Montserrat** para textos de leitura fluida.

---

## ✨ Funcionalidades Principais

1. **Hero Section Impactante:** Apresentação da recepção luxuosa da clínica, integrando o CTA principal pulsante focado em agendamento de consultas.
2. **Slider de Comparação Antes/Depois (Otomodelação):** Mecanismo interativo que permite deslizar a barra em tempo real para comparar resultados do procedimento, compatível com mouses e telas de toque (mobile).
3. **Vitrine de Procedimentos:** Apresentação elegante das opções de *Harmonização Orofacial* (Preenchimento com Ácido Hialurônico, Toxina Botulínica e Bioestimuladores de Colágeno).
4. **Bio e Autoridade Médica:** Destaque para a trajetória e compromisso técnico da **Dra. Gessica**.
5. **FAQ Inteligente:** Seção de dúvidas frequentes com animação de acordeão (auto-colapso) para melhor experiência do usuário.
6. **Integração Direta com WhatsApp:** CTAs distribuídos estrategicamente com links e mensagens personalizadas para Sarandi/PR.

---

## 🚀 Tecnologias Utilizadas

* **HTML5 Semântico:** Estrutura focada em SEO e acessibilidade.
* **Vanilla CSS3:** Layout responsivo, variáveis CSS, transições fluidas e micro-animações.
* **JavaScript ES6:** Lógica nativa de alto desempenho para o slider e animações na rolagem da tela.
* **Vite:** Ferramenta rápida para o servidor de desenvolvimento local.

---

## 💻 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/nexaonesolutions/Reisclinic.git
   ```
2. Entre no diretório do projeto:
   ```bash
   cd NewProject
   ```
3. Instale o Vite localmente ou execute diretamente via NPX:
   ```bash
   npx vite --open
   ```
