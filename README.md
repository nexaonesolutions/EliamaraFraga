# Eliamara Fraga | Centro Estético de Alta Performance & Harmonização Avançada 💎

Landing page Single-Page Application (SPA) de altíssima performance desenvolvida sob medida para o **Centro Estético Eliamara Fraga**, uma clínica de estética avançada. O projeto foi projetado com foco no **mercado de luxo**, utilizando uma estética clean, científica e premium ("Scientific Luxury"), otimizada especificamente para tráfego móvel proveniente do Instagram.

---

## 🎨 Identidade Visual (Scientific Luxury)

O projeto foi construído seguindo uma estética minimalista, clínica e luxuosa:
* **Paleta de Cores:** Fundo Off-White (`#FAFAFA`) para limpeza, detalhes em gradiente Rose Gold/Champagne metálico (`#D4AF37` / `#C5A059`) para exclusividade e alta tecnologia, e textos em Charcoal (`#222222`) para legibilidade e elegância contemporânea.
* **Tipografia:** Serifada clássica e sofisticada **Playfair Display** para os Títulos (transmitindo tradição, elegância e autoridade médica) e Sans-serif geométrica limpa **Inter** para o corpo do texto (proporcionando leitura fluida e moderna).
* **Animações e Micro-interações:**
  - **Scroll Reveal:** Animações nativas acionadas por `IntersectionObserver` em JavaScript para surgimento gradativo do conteúdo ao rolar a página.
  - **Hover Effects:** Elevação de cards de procedimentos, realce de bordas em Rose Gold e transições suaves de opacidade.
  - **CTA Metálico:** Efeito pulsar suave nos botões principais e um reflexo metálico brilhante periódico ("metallic flash").
  - **Botão Sticky WhatsApp:** Botão de WhatsApp flutuante no canto inferior direito para navegação mobile com efeito de ondas de pulso discretas (`.whatsapp-ripple`).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Estrutura focada em acessibilidade e SEO técnico.
* **Tailwind CSS v3 (Purged):** Utilização de classes utilitárias de luxo com compilação altamente otimizada, pesando apenas **24.52 kB** em produção.
* **JavaScript ES6 (Vanilla):** Lógica modularizada e extremamente resiliente, contendo blocos Try-Catch para prevenção e tratamento de exceções.
* **Vite:** Empacotamento de altíssima performance gerando uma build estática limpa e sem overhead de frameworks reativos pesados.

## 💻 Como Executar Localmente

1. Instale as dependências do projeto:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Para compilar a versão final otimizada para produção:
   ```bash
   npm run build
   ```
