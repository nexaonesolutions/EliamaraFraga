# Dra. Mary Conceição | Estética Biomédica de Luxo 💎

Landing page de alta conversão desenvolvida sob medida para a **Dra. Mary Conceição**, Biomédica Esteta especialista em rejuvenescimento avançado e gerenciamento de envelhecimento facial. O projeto combina rigor de saúde com sofisticação de alto padrão no conceito de **"Scientific Luxury"**.

---

## 🎨 Identidade Visual (Scientific Luxury)

O projeto foi construído seguindo uma estética minimalista, clínica e luxuosa:
* **Paleta de Cores:** Gradients metálicos de *Ouro*, tons ricos e profundos de *Verde Esmeralda* e fundo *Off-White* limpo.
* **Tipografia:** Combinação elegante da fonte serifada clássica **Cormorant Garamond** para títulos e **Plus Jakarta Sans** para textos técnicos e fluidos de leitura.
* **Efeitos de Interface:** Navegação persistente com *Glassmorphic Blur* (desfoque de fundo de 18px), sombras ultra-suaves, transições premium e micro-animações de brilho metálico nos botões de conversão.

---

## ✨ Funcionalidades Principais

1. **Hero Section de Autoridade:** Foco no rigor técnico e autoridade da Dra. Mary, com selo dinâmico flutuante de atendimento exclusivo.
2. **Pilares Clínicos:** Apresentação elegante das diretrizes da clínica (Rigor Científico, Protocolos Personalizados e Estética Natural).
3. **Ciclo de Gerenciamento de Pele:** Componente interativo que guia o usuário pelas 3 fases estruturadas do tratamento cutâneo integrado (Preparação, Bioestimulação e Lapidação).
4. **Fato Científico de Destaque:** Painel clínico informativo a respeito do envelhecimento dérmico e a perda natural anual de colágeno.
5. **Vitrine de Procedimentos:** Cards refinados com efeito hover para os principais procedimentos injetáveis (Toxina Botulínica, Preenchimento Facial e Bioestimuladores de Colágeno).
6. **FAQ com Acordeão Dinâmico:** Seção de dúvidas clínicas frequentes com animação de auto-colapso para melhor experiência.
7. **Integração com WhatsApp:** CTAs distribuídos estrategicamente com links e mensagens personalizadas redirecionando para a equipe do VIP Concierge.

---

## 🚀 Tecnologias Utilizadas

* **HTML5 Semântico:** Estrutura focada em acessibilidade e SEO técnico.
* **Vanilla CSS3:** Variáveis de design, layouts flexíveis, efeitos de desfoque de fundo e animações nativas.
* **JavaScript ES6:** Lógica modularizada e extremamente resiliente, contendo blocos Try-Catch para prevenção e tratamento de exceções.
* **Vite:** Ferramenta rápida de empacotamento e compilação para ambiente de produção.

## 💻 Como Executar Localmente

1. Entre no diretório do projeto:
   ```bash
   cd NewProject
   ```
2. Instale o Vite localmente ou execute diretamente via NPX:
   ```bash
   npx vite --open
   ```
3. Para compilar a versão final otimizada para produção:
   ```bash
   npx vite build
   ```
